# Spin Hydrodynamics Data and Code Repository
This repository contains the data and scripts used in the manuscript:
Hidefumi Matsuda et al.,
"Achieving angular-momentum conservation with physics-informed neural networks in computational relativistic spin hydrodynamics"

## Contents
- data/ : numerical data used in the analysis
- scripts/ : scripts to reproduce figures
- configs/ : parameter settings used in simulations

## Reproducibility
The repository provides the data and scripts necessary to reproduce the main numerical results and figures presented in the manuscript.
